该下哪个？

  • …-arm64-v8a.apk —— 推荐，绝大多数手机（近几年的机型都选这个）
  • …-armeabi-v7a.apk —— 老 32 位机型
  • ….apk（通用包）—— 不确定或模拟器；体积大一倍，但一定能装

三个包功能完全一样，只是包含的 CPU 架构不同；装错会提示「应用未安装」，换另一个文件即可。

公告

如何关闭启动时的版权弹窗

  1. 打开应用，进入 设置
  2. 进入 应用信息
  3. 进入 高级设置
  4. 打开 关闭启动前弹窗（从下次启动起生效）

同一个页面还能关闭「启动时检查公告」和「启动时自动检查更新」。
